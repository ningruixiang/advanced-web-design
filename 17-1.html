一、什么是 JSON
JavaScript Object Notation（对象表示法），一种轻量的数据交换格式。结构上就是 JavaScript 的对象 / 数组，语法几乎一模一样。
一个真实例子：学生信息 JSON 文本 
{
  "name": "宁瑞祥",
  "age": 20,
  "major": "计算机科学与技术",
  "isStudent": true,
  "grade": null,
  "hobbies": [
    "前端开发",
    "打篮球",
    "听音乐"
  ]
}
类型：object · 合法 JSON 里可以出现：对象 数组 字符串 数字 true/false null
二、六种合法值
JSON 规定，只有这 6 种值是合法的。函数、undefined、Symbol、Date 对象——这些直接放进去都会出问题。
✅ 合法的 6 种
"str":  "你好"        // 字符串，双引号
"num":  42 / 3.14   // 数字（含小数）
"bool": true          // 布尔，小写
"nil":  null         // 空值，小写
"arr":  [1, 2, 3]   // 数组
"obj":  {"a": 1}   // 对象
❌ 容易踩的坑
"fn": "function(){}"  // ❌ 不支持函数
"u": "undefined"       // ❌ 不支持 undefined
"date": "2024-01-01T..." // ⚠️ Date 只能转字符串
"key": '单引号'       // ❌ 键和字符串必须双引号
"trail": 1, null,  // ❌ 不允许尾随逗号
