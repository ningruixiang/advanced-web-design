循环结构（Loop）

重复执行一段代码。点击「运行」实时看每段循环的输出结果。

01

for已知次数

三段式：初始化 + 条件 + 更新。最常用的循环，次数明确时首选。

for (let i = 1; i <= 5; i++) {
    console.log("第 " + i + " 次");
}
02

while先判断

先判断条件，条件为真才执行循环体。次数未知时使用。

let n = 1;
while (n <= 3) {
    console.log("n = " + n);
    n++;
}
03

do...while先执行

先执行一次循环体，再判断条件。无论条件真假，至少跑一次。

let i = 10;
do {
    console.log("至少跑一次");
    i++;
} while (i < 3);
04

for...of遍历数组/字符串

ES6 新语法，直接拿到数组或字符串的元素值，写起来最简洁。

const fruits = ["苹果", "香蕉", "橙子"];
for (let f of fruits) {
    console.log("水果：", f);
}
// 字符串也能遍历
for (let c of "Hi") { console.log(c); }
05

for...in遍历对象键

遍历对象的可枚举属性名（key）。数组也能用，但不推荐——可能遍历到继承属性。

const stu = { name: "宁瑞祥", age: 21, id: "2001010503" };
for (let k in stu) {
    console.log(k + " → " + stu[k]);
}

条件结构（Conditional）

根据条件真假走不同分支。每种条件都绑定一个实际场景。

06

if / else if / else

多分支判断，从上到下依次检查，命中即停止。下面演示分数等级判定。

function grade(score) {
    if (score >= 90) return "A 优秀";
    else if (score >= 80) return "B 良好";
    else if (score >= 60) return "C 及格";
    else return "D 不及格";
}
for (let s of [95, 85, 70, 55]) {
    console.log(s + " 分 → " + grade(s));
}
07

三元运算符条件 ? A : B

if/else 的极简写法。条件为真取 A，为假取 B。常用于简单赋值。

let age = 21;
let status = age >= 18 ? "成年" : "未成年";
console.log(age + " 岁：" + status);

// 嵌套也可以，但别太深
let score = 85;
let level = score >= 90 ? "A"
            : score >= 60 ? "B" : "C";
console.log("等级：", level);
08

switch多值匹配

根据同一个表达式的不同取值走不同分支。记得每个 case 末尾加 break，否则会"穿透"到下一个 case。

let day = 3;
switch (day) {
    case 1: console.log("周一"); break;
    case 2: console.log("周二"); break;
    case 3: console.log("周三"); break;
    case 4: console.log("周四"); break;
    case 5: console.log("周五"); break;
    default: console.log("周末");
}
09

break / continue循环控制

break 立即跳出整个循环；continue 跳过本次迭代、继续下一轮。

console.log("--- break：遇到 7 就停 ---");
for (let i = 1; i <= 10; i++) {
    if (i === 7) break;
    console.log(i);
}
console.log("--- continue：跳过偶数 ---");
for (let i = 1; i <= 8; i++) {
    if (i % 2 === 0) continue;
    console.log(i);
}

速查表

循环与条件的一句话总结，方便回顾。

语法类型适用场景关键要点
for (init; cond; update)循环次数明确三段式，最通用
while (cond)循环次数未知，先判断别忘更新计数器，否则死循环
do { } while (cond)循环至少执行一次入口条件不满足也会跑一次
for (let v of arr)循环遍历数组/字符串直接拿到元素值，ES6+
for (let k in obj)循环遍历对象键数组慎用，可能遍历继承属性
if / else if / else条件多分支从上到下命中即停
cond ? A : B条件二选一赋值if/else 极简版
switch (val)条件同一值多分支每个 case 记得 break
break控制跳出当前循环不再执行剩余迭代
continue控制跳过本次迭代继续下一轮循环
