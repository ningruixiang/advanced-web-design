六大类型一览

点击卡片下方的示例按钮，实时查看值的变化与 typeof 检测结果；悬停卡片体验 3D 视差。

01

Number 数值typeof → "number"

整数与浮点数统称，含特殊值 Infinity（无穷）与 NaN（非数值）。

42
typeof 值 → "number"
02

String 字符串typeof → "string"

由单引号、双引号或反引号包裹的文本，"123" 加引号后不再是数值。

"宁瑞祥"
typeof 值 → "string"
03

Boolean 布尔typeof → "boolean"

逻辑值只有 true 与 false 两个，常用于条件判断与开关状态。

true
typeof 值 → "boolean"
04

Undefined 未定义typeof → "undefined"

变量声明后尚未赋值时的默认值，表示"此处应有值但还没有"。

undefined
typeof 值 → "undefined"
05

Null 空值typeof → "object" ⚠

表示"刻意为空"的占位值。注意：typeof null 返回 "object"，是 JS 的历史遗留 Bug。

null
typeof 值 → "object"
⚠ 历史 Bug：null 并不是对象
06

Object 对象typeof → "object"

键值对集合；数组与函数同属对象体系，数组 typeof 仍为 "object"，函数则特殊返回 "function"。

{ name: "宁瑞祥" }
typeof 值 → "object"
